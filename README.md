# lem-module

## Prerequisites
- Terraform knowledge.
- Steps
  - terraform init
  - terraform plan
  - terraform apply
  - terraform destroy

It may ask for SSH public key or you can define it to terraform.tfvars like this

resource_group = "name-of-resource-group"

ssh_public_key = "Complete ssh-rsa public key"
